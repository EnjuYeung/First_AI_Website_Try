## 产品与实现边界

定位：个人和家庭日常使用的周期支出记录工具。核心任务是看清费用、下一笔扣费、需要处理的记录，并快速添加或修改订阅。

现有栈为 React 19 + TypeScript + Vite 6 + Tailwind 4 + Lucide。已有本地字体 Archivo、IBM Plex Sans、IBM Plex Mono，自定义 ModalDialog、筛选器、订阅卡片/表格、金额组件与续费时间轴。

本次优先复用上述组件；不增加组件库、路由库或远程字体。图表优先使用带可见数值的简洁条形图和现有账期事件；只有存在实际交互需求时才评估 Recharts。费用计算、账期推进、筛选口径、保存和冲突处理保持原有行为。后端 API、schema、数据库与业务数据不在改动范围。

## 设计系统提案

### 技能检索与取舍

已执行 `ui-ux-pro-max/scripts/search.py` 的 `--design-system`，并用明确领域检索验证以下匹配：

- `Minimalism & Swiss Style` → `minimalism-and-swiss-style`：网格、无衬线、留白、强层级、细边框、无装饰性渐变。
- `Bento Box Grid` → `bento-box-grid`：功能模块按重要性采用不同跨度；4→2→1 的适配规则。卡片缩放建议不采用，避免数据界面跳动。
- `Modern Financial Dashboard` → `financial-dashboard`：币种和精度一致、金额优先、状态可辨识、图表服务读数。企业收入/利润/审计指标不适用于本产品。
- `Swiss financial interface sans serif` → `Minimal Swiss`：统一无衬线和字重。为复用现有资源，沿用本地 IBM Plex Sans，而非再增加 Inter。
- `category expense comparison trend` → 分类条形图、时间序列图；需要直接数值、文字解释和数据表替代。
- `form mobile field grouping` → 可见标签、关联错误、提交反馈。React 栈检索确认复用受控表单与组合式组件。

自动聚合结果中的营销官网布局、手写字体及企业入口不适用，已舍弃，未将未验证输出覆盖到项目已有 MASTER.md。本提案以用户要求和上述已核对结果为依据。

### 字体、尺寸与密度

- 主体和页面标题统一使用本地 IBM Plex Sans，品牌文字保留 Archivo；数据使用现有 IBM Plex Mono 与 tabular-nums。
- 页面标题桌面 28–32px、手机 24px；核心费用 28–36px；正文与表单输入 16px；次级标签 13–14px。
- 间距 4 / 8 / 12 / 16 / 24 / 32 / 48px。手机页面留白 16px，桌面 24–32px；卡片间距 16–24px，内边距 20–24px。
- 控件圆角 8–10px、卡片 16px、详情及弹窗 20px。表面优先细边框，阴影仅用于浮层及必要层级。
- 桌面内容最大 1440px；>=1024px 为 12 列功能网格，768–1023px 两列，小屏单列，金额摘要必要时两列。内容驱动跨度，不造空白装饰卡片。
- 桌面保持顶部导航；手机保持底部导航，建议增加“支出统计”后共四项。新增/编辑为同一流程。

### 交互状态

- 全部组件定义默认、悬停、焦点、按下、禁用、加载、失败、成功状态；成功轻量反馈，不做庆祝动画。
- 只在用户操作后对颜色、透明度进行 120–180ms 过渡；不做卡片位移、金额数值滚动、无意义入场动画。
- 支持 reduced-motion，焦点环即时显示。图标按钮具名，装饰图标从辅助技术中隐藏。
- 手机输入目标高度至少 44px，金额字段使用 decimal 键盘，输入文字 16px。保存区考虑安全区和软键盘，不遮挡焦点控件。
- 弹窗支持 Escape、焦点约束与返回；上传、保存失败、冲突等现有行为完整保留。
- 保留用户已有壁纸、上传与透明度设置；默认外观使用实色面板，输入和详情浮层保持可读。

## 费用语义与明确不新增的数据

1. 月度费用指当月账期事件的估算总额，不是年费除以 12，也不是银行卡实际流水。
2. 年度费用指当前日历年推算的总费用，不是月费 × 12 的统一年化公式。现有口径不变。
3. 每笔费用保留原币；汇总沿用美元。缺失汇率时不能当作 0 消失，需保留已有排除提示。
4. 活跃状态不代表服务商自动扣款已启用；提醒开关不代表自动续订；下次账单日不代表服务到期日。
5. 个人/家庭定位体现在易读、易录入和低密度设计；当前没有成员或分摊字段，不添加虚构成员数据或新权限流程。
