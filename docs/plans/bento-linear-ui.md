# Bento + Linear UI 重构方案

状态：已实现并完成本地验收。用户回复“都按推荐”，采纳下列三个推荐项。

## 目标与已确定约束

- 视觉方向为 Bento + Linear。
- 首页按概览页 `Dashboard` 理解，布局保持现状。
- 现有项目为 React 19、Vite 6、Tailwind 4；图标使用 Lucide，自托管字体为 Archivo 与 IBM Plex Sans/Mono。
- 当前生产为一个应用容器；本次 UI 验收使用合成数据，不读取真实配置值或账户数据。

## 首页布局基线

- 内容容器最大宽度 1440px，现有页边距和断点由 `App.tsx` 控制。
- 顶栏高 64px；桌面使用顶部三个导航入口，小屏使用底部三个导航入口。
- 首页顺序：月标题、条件显示的汇率提示、全宽续费时间轴、四项指标、近期付款与待关注。
- 四项指标小屏两列、md 起四列；下方账单小屏单列、lg 起等宽两列。
- 时间轴保留独立横向滚动、最小 1120px × 390px 画布、现有日期线与三条事件轨道定位。
- 全局字体、字号、间距、边框宽度及共享卡片样式也会改变首页几何，不能只靠不修改 Dashboard JSX 来保证布局不变。

## 现有功能边界

- 浅色、深色及系统跟随；default、blue、violet、rose 四套主题色。
- 壁纸地址、上传与移除、模糊、遮罩和面板透明度。
- 订阅搜索、多选筛选、表格排序、卡片/表格切换、选择与批量删除、编辑、复制及续订反馈。
- 设置中的 API、币种、通知、安全与通用配置；保留异步保存、验证、冲突、错误和加载状态。
- 登录与 TOTP、订阅编辑草稿、焦点管理及弹窗关闭行为。

## 已确认决策

1. 首页保留结构、位置、顺序、尺寸比例和断点，统一视觉皮肤。
2. Linear 为主、Bento 为辅：中性冷白/石墨底、细边框、轻阴影、清楚的信息层级和克制动效。
3. 全站统一；首页以外允许优化内部布局，完整保留功能及导航位置。

## 决策树

```text
Bento + Linear UI 重构
├── 首页：冻结布局，允许皮肤变化；固定合成数据对比几何
├── 视觉：Linear 主导；Bento 用于功能分组；保留字体与 Lucide
└── 全站覆盖
    ├── 订阅页：统一工具栏、表格与卡片外观
    ├── 设置页：独立次级导航、Bento 分组、完整主题和壁纸控制
    ├── 登录、订阅编辑及反馈弹窗：统一表面及输入控件
    └── 验收：响应式、明暗/四色/系统主题、键盘与原有功能回归
```

## 已核对的设计依据

- `ui-ux-pro-max` 的 `Bento Box Grid`（`bento-box-grid`）匹配模块卡片、中性底色、品牌强调色、轻阴影、明暗主题与响应式；其中改变网格跨度或 hover 缩放的建议受本项目首页约束限制，不直接套用。
- 首次自动设计系统搜索返回营销漏斗及高饱和彩色风格，与任务不符，已舍弃；未持久化该输出。
- React 栈搜索确认使用组合式组件和职责清晰的复用边界；这不要求更换图标库或组件框架。
- [Linear 官方产品展示](https://linear.app/) 用作视觉参考；具体规范已记录到 [设计系统](../../design-system/subm/MASTER.md)。

## 验收准备

- 通过隔离的合成账户和 API 响应预览 UI，不登录或读取生产真实账户。
- 固定相同数据、时间、视口与主题，对比首页改造前后的模块边界与排列。
- 关注 375px、768px、1024px、1440px、明暗主题、主题色及壁纸透明度。
- 核对键盘、焦点、可读对比度、表单错误、加载/空状态和 reduced-motion。

## 当前执行状态

视觉及组件改造已落地；`Dashboard.tsx` 和 `RenewalRail.tsx` 未改动。反馈、确认与设置错误弹窗共用 `ModalDialog`，统一焦点循环、Escape、焦点返回、语义标题和不透明表面。
