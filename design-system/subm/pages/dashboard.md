# Dashboard · 布局冻结

本页优先级高于 [MASTER.md](../MASTER.md) 中的布局建议。用户明确要求首页布局不动，并选择允许统一视觉换肤。

## 固定结构

1. 月份标题和说明，以及有条件出现的汇率提示。
2. 全宽续费时间轴。
3. 四项指标，小屏两列、md 起四列。
4. 近期付款与待关注，小屏单列、lg 起等宽两列，间距 24px。

- 主容器最大 1440px，页边距和顶边距保留 `App.tsx` 原值及断点。
- 顶栏 64px 加 1px 边框；桌面顶栏导航、小屏底栏导航的位置不变。
- 时间轴画布最小宽 1120px、高 390px，保留局部横向滚动、48px 轨道边距、72px 日期轴底边距和三条事件轨道。
- 标题字体、字号、行高、内边距、边框宽度、模块顺序和宽高比例保持不变。

允许改动：颜色、边框颜色、圆角、阴影和焦点外观。共享样式的修改同样受此规则限制，不能只靠不改 `Dashboard.tsx` 保证布局不变。
