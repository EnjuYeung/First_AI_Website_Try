# Subm · Bento + Linear

2026-10-16。用户选择全部推荐项：Linear 为主、Bento 为辅；全站统一视觉；首页结构冻结、允许换肤。实现以 `styles.css` 为准，Dashboard 的约束见 [dashboard.md](pages/dashboard.md)。

## 视觉原则

- 冷白或石墨底色、清楚的表面层级、细边框、轻阴影；强调色用于操作、当前项和业务状态。
- Bento 用于设置和表单的功能分组，每组拥有标题、内容与操作；按内容决定跨度，避免装饰性空卡片。
- 保留现有顶部导航、移动端底部导航、Lucide 图标及自托管字体；不引入组件库或远程字体。
- 首页维持原有排版和密度，工作页面采用更紧凑的标题。交互反馈不使用卡片位移或缩放。

`default`、`blue`、`violet`、`rose` 共用中性底色，保留各自强调色。警示使用琥珀色和珊瑚红。强调背景上的文字通过 `on-accent` 随明暗模式切换；浅强调底上的小字使用 `rail-teal-ink`，浅色四套分别为 `#1e6966`、`#1d4ed8`、`#6d28d9`、`#be123c`，深色沿用各自浅亮强调色。

- 卡片圆角 16px，主面板 20px，控件 9px。
- 设置分组间距 20px，卡片内边距 20px；桌面设置侧栏宽 184px、与内容间距 24px。
- 工作页面标题 IBM Plex Sans，1.7–2.1rem；首页标题继续使用 Archivo 和原有尺寸。金额和时间使用 IBM Plex Mono。
- 反馈过渡 150ms 左右，继承现有入场动效；`prefers-reduced-motion` 下关闭持续或大幅动效。

## 组件与响应式

- `.statement-card` 与 `.subscription-card` 使用统一表面、边框和轻阴影。
- 订阅工具栏使用 16px 内边距；保留所有筛选、排序、选择、批量操作和卡片/表格切换。
- 设置小屏为横向滚动次级导航和单列内容；768px 起使用左侧 sticky 导航；1100px 起使用双列 Bento 分组。API、币种及通知的密集内容保留足够宽度。
- 订阅表单 768px 起双列，价格/币种/周期/分类及通知组跨列；小屏单列并在弹窗内部滚动。
- 壁纸继续支持 URL、上传、移除、模糊、遮罩和 35–100% 面板透明度。对话框始终采用不透明表面，避免背景干扰输入。
- 登录使用石墨色说明面板与独立表单卡片；移动端收起说明面板。

## 交互与可访问性

- 可见的 2px 焦点描边；提供跳至主内容链接、表单标签、图标按钮名称及当前/选中状态。
- 分类和支付方式保留拖动排序，补充键盘及触屏可用的上下移动按钮；首尾移动按钮禁用。
- 错误弹窗具有标题、描述、焦点约束、Escape 关闭及焦点返回；保存反馈使用 live status，移动端避开底部导航。
- 保留全部验证、保存、冲突、失败、空状态和加载流程；主题偏好仍归浏览器本地，服务器设置仍通过原有字段补丁保存。

## 验收方式

使用固定日期与合成账户的浏览器 API 拦截进行截图及交互检查，不读取生产账户数据。首页对比 375、768、1440px 的浅深两种模式，测量顶栏、标题、时间轴、指标和账单区的边界。其余页面扩展至 1024px，并核对主题色、系统主题、键盘操作、reduced-motion 与整页水平溢出。

设计依据：`ui-ux-pro-max` 的 Bento Box Grid 样式及 React 组合原则；[Linear 官方界面](https://linear.app/) 用作中性色、边框和信息密度的视觉参考。
